🌐 Responsive Landing Page

Live Demo: https://tanishkamandil-07.github.io/Responsive-landing-Page/

A clean and fully responsive landing page built using HTML, CSS, and JavaScript. This project showcases modern layout, responsive design principles, and user-friendly interface that works seamlessly on mobile and desktop.

🧠 Project Overview

This landing page project demonstrates:

Responsive web layout (mobile, tablet, desktop)

Navigation bar with smooth scrolling effect

Hero section with call-to-action

Informative sections with visuals and text

Modern and minimal UI design

Semantic HTML structure and CSS styling

Landing pages like this are commonly used to introduce a product, service, or personal brand — and they are an excellent way to strengthen your frontend development skills in HTML & CSS.

🚀 How to Run Locally

To run this project on your local machine:

Clone the repository:

git clone https://github.com/tanishkamandil-07/Responsive-landing-Page.git

Open the folder in your file explorer.

Open index.html in your favorite browser (Chrome, Firefox, Safari).

No server setup or installation is required — this is a static front-end project.
